# Qt 计算器（实验1：带键盘事件的计算器）

东莞理工学院《Qt应用程序开发》实验1作业。参考 Windows 计算器界面的四则运算计算器，
支持鼠标与键盘两套输入，二者复用同一套处理逻辑。

## 功能

- 四则运算 + - × ÷、连续运算（如 1+2+3）
- 小数输入（防止连续小数点）、退格、清除 C / CE、正负号 ±
- 一元运算：%、1/x、x²、√x
- 错误处理：除数为 0、负数开方，错误后按数字自动重新开始
- 显示屏字号自适应，长错误提示不被截断

## 键盘键位

| 键 | 功能 |
| --- | --- |
| 0-9 / 小键盘 | 数字 |
| . | 小数点 |
| + - * / | 运算符 |
| Enter / = | 等号 |
| Backspace | 退格 |
| Esc | 全部清除 C |
| Delete | 清除当前输入 CE |

## 编译

Qt 5.15+ / Qt 6 均可（Qt 5.15.2 + MinGW 8.1 测试通过）：

```
qmake Calculator.pro
mingw32-make release
```

界面由 UI 设计器的 `mainwindow.ui` 定义（6×4 按钮网格 + QSS 深色主题样式表），
`mainwindow.cpp` 通过 `ui->setupUi()` 加载。
